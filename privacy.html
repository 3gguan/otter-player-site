你的音乐与文件 你的音樂與檔案 Your Music and Files 音楽とファイルについて

  • 音乐文件不会被上传到任何服务器。它们始终留在你的设备上，或留在你自己配置的网络源里。
  • 网络音乐源的请求只发往你自己指定的地址。当你添加 SMB、NFS、WebDAV 或 DLNA 网络源时，App 只会连接你填写的那个服务器地址。这些地址、用户名和密码加密保存在设备本地，不会外传。
  • 局域网设备搜索使用 Bonjour / SSDP 组播，仅在同一局域网内进行，不会把结果发送到互联网。
  • 文件传输会在你的手机与同一局域网内的电脑之间建立一个本地 HTTP 服务，只在开启期间运行且需保持 App 在前台。传输内容不经过任何中转服务器。
  • 音樂檔案不會被上傳到任何伺服器。它們始終留在你的裝置上，或留在你自己設定的網路來源裡。
  • 網路音樂來源的請求只發往你自己指定的位址。當你加入 SMB、NFS、WebDAV 或 DLNA 網路來源時，App 只會連線你填寫的那個伺服器位址。這些位址、使用者名稱和密碼加密保存在裝置本機，不會外傳。
  • 區域網路裝置搜尋使用 Bonjour / SSDP 組播，僅在同一個區域網路內進行，不會把結果傳送到網際網路。
  • 檔案傳輸會在你的手機與同一區域網路內的電腦之間建立本機 HTTP 服務，只在開啟期間運作且需保持 App 在前景。傳輸內容不經過任何中轉伺服器。
  • Your music files are never uploaded anywhere. They stay on your device, or on the network source you configured yourself.
  • Network music source requests only go to addresses you specify. When you add an SMB, NFS, WebDAV or DLNA source, the app connects only to the server address you entered. Those addresses, usernames and passwords are stored encrypted on the device and are never sent anywhere else.
  • Local device discovery uses Bonjour / SSDP multicast on your local network only; results are never sent to the internet.
  • File Transfer runs a local HTTP service between your phone and a computer on the same local network. It only runs while you have it switched on and the app in the foreground. Nothing is relayed through any third-party server.
  • 音楽ファイルが外部にアップロードされることはありません。ファイルはお客様のデバイス、またはお客様が設定したネットワークソースに留まります。
  • ネットワーク音楽ソースへの通信は、お客様が指定したアドレスにのみ行われます。SMB、NFS、WebDAV、DLNA のソースを追加した場合、アプリは入力されたサーバーアドレスにのみ接続します。アドレス・ユーザー名・パスワードは端末内に暗号化して保存され、外部に送信されません。
  • ローカルネットワークの機器検索は Bonjour / SSDP のマルチキャストを使用し、同じネットワーク内でのみ行われます。結果がインターネットに送信されることはありません。
  • ファイル転送は、iPhone と同じネットワーク上のパソコンとの間にローカルの HTTP サービスを用意するものです。オンにしている間かつアプリが前面にある間だけ動作し、第三者のサーバーを経由しません。

可选的联网功能 選用的連網功能 Optional Network Features 任意のネットワーク機能

以下两项默认关闭，只有你主动开启并满足条件时才会联网；请求直接发往对应服务，不经过我方服务器。

在线歌词（设置 → 歌词 → 在线歌词）

  • 什么时候会查询：只有当一首歌既没有内嵌歌词、同目录也没有歌词文件，且你已经打开该开关时。
  • 发送什么：歌曲名称、艺术家、专辑、时长。不发送音频文件、封面、文件名、文件路径、账号或设备标识。
  • 发给谁：lrclib.net（LRCLIB，公开的社区歌词数据库）。该服务对收到的查询按它自己的隐私政策处理。
  • 结果存在哪：返回的歌词文本缓存在本机，用于之后直接显示，可按下面「保存在设备上的数据」中的方法清除。

AI 歌词翻译（设置 → 歌词 → AI 歌词翻译）

  • 什么时候会联网：只有你在设置里填好了翻译服务地址并触发翻译时。
  • 发送什么：需要翻译的歌词文本。
  • 发给谁：你自己填写的那个地址。如果那是第三方服务，则受该服务的条款与隐私政策约束——我们不运营翻译服务，也不会看到这些请求。
  • 留空时，App 不会发起任何翻译请求。

以下兩項預設關閉，只有你主動開啟並符合條件時才會連網；請求直接送往對應服務，不經過我方伺服器。

線上歌詞（設定 → 歌詞 → 線上歌詞）

  • 什麼時候會查詢：只有當一首歌既沒有內嵌歌詞、同資料夾也沒有歌詞檔案，且你已經開啟該開關時。
  • 傳送什麼：歌曲名稱、演出者、專輯、長度。不傳送音訊檔案、封面、檔名、檔案路徑、帳號或裝置識別碼。
  • 傳給誰：lrclib.net（LRCLIB，公開的社群歌詞資料庫）。該服務對收到的查詢依其自身隱私權政策處理。
  • 結果存在哪：回傳的歌詞文字會快取在本機，供之後直接顯示，可依下面「保存在裝置上的資料」中的方法清除。

AI 歌詞翻譯（設定 → 歌詞 → AI 歌詞翻譯）

  • 什麼時候會連網：只有你在設定裡填好翻譯服務位址並觸發翻譯時。
  • 傳送什麼：需要翻譯的歌詞文字。
  • 傳給誰：你自己填寫的那個位址。如果那是第三方服務，則受該服務的條款與隱私權政策約束——我們不經營翻譯服務，也不會看到這些請求。
  • 留空時，App 不會發出任何翻譯請求。

Both features below are off by default; they go online only when you turn them on and the conditions are met. Requests go straight to the service concerned — never through a server of ours.

Online Lyrics (Settings → Lyrics → Online Lyrics)

  • When it queries: only when a track has no embedded lyrics and no lyrics file in the same folder, and only if you have switched it on.
  • What is sent: title, artist, album and duration. No audio file, no artwork, no file name, no file path, no account and no device identifier.
  • Who receives it: lrclib.net (LRCLIB), a public community lyrics database. It handles those queries under its own privacy policy.
  • Where results go: the returned lyrics are cached on your device so they can be shown again later; they can be cleared as described in "Data Stored on Your Device" below.

AI Lyrics Translation (Settings → Lyrics → AI Lyrics Translation)

  • When it goes online: only after you have entered a translation service address in Settings and triggered a translation.
  • What is sent: the lyrics text that needs translating.
  • Who receives it: the address you entered. If that is a third-party service, its terms and privacy policy apply — we operate no translation service and never see those requests.
  • Left empty, the feature sends nothing at all.

以下の 2 機能は初期状態でオフです。お客様が有効にし、条件を満たした場合にのみ通信します。リクエストは該当サービスに直接送られ、当方のサーバーを経由しません。

オンライン歌詞（設定 → 歌詞 → オンライン歌詞）

  • いつ問い合わせるか：曲に埋め込み歌詞がなく、同じフォルダに歌詞ファイルもなく、かつこのスイッチをオンにしている場合のみです。
  • 送信する内容：曲名、アーティスト、アルバム、再生時間。音声ファイル、ジャケット、ファイル名、ファイルパス、アカウント、端末識別子は送信しません。
  • 送信先：lrclib.net（LRCLIB。公開のコミュニティ歌詞データベース）。受信した問い合わせは同サービスのプライバシーポリシーに従って扱われます。
  • 結果の保存先：返された歌詞テキストは端末内にキャッシュされ、後から再表示できます。下記「端末内に保存されるデータ」の方法で削除できます。

AI 歌詞翻訳（設定 → 歌詞 → AI 歌詞翻訳）

  • いつ通信するか：設定で翻訳サービスのアドレスを入力し、翻訳を実行した場合のみです。
  • 送信する内容：翻訳対象の歌詞テキスト。
  • 送信先：お客様が入力したアドレス。第三者サービスであれば、そのサービスの規約とプライバシーポリシーが適用されます。当方は翻訳サービスを運営しておらず、これらのリクエストを目にすることもありません。
  • 空欄のままでは、翻訳リクエストは一切送信されません。

保存在设备上的数据 保存在裝置上的資料 Data Stored on Your Device 端末内に保存されるデータ

以下内容保存在 App 自己的沙盒里，卸载 App 即随之删除，不会离开你的设备：

  • 音乐库索引、收藏、播放列表、播放队列与播放记录
  • 你添加的音乐源地址与登录凭据（加密保存）
  • 封面缩略图与网络音频缓存（可在「设置 → 清理缓存」中随时清除）
  • 歌词缓存（本地歌词文件、以及你开启在线歌词后从 LRCLIB 取得的文本）与 AI 翻译结果（同样可清除）
  • AI 翻译的服务地址、模型名与 API Key（若你填写了）——密钥只保存在系统 Keychain 中

以下內容保存在 App 自己的沙盒裡，移除 App 即隨之刪除，不會離開你的裝置：

  • 音樂庫索引、收藏、播放清單、播放佇列與播放記錄
  • 你加入的音樂源位址與登入憑證（加密保存）
  • 封面縮圖與網路音訊快取（可在「設定 → 清理快取」中隨時清除）
  • 歌詞快取（本機歌詞檔案，以及你開啟線上歌詞後從 LRCLIB 取得的文字）與 AI 翻譯結果（同樣可清除）
  • AI 翻譯的服務位址、模型名稱與 API Key（若你填寫了）——金鑰只保存在系統 Keychain 中

The following is kept in the app's own sandbox, is deleted when you delete the app, and never leaves your device:

  • Library index, favorites, playlists, play queue and listening history
  • The source addresses and credentials you added (stored encrypted)
  • Artwork thumbnails and network audio cache (clearable anytime from Settings → Clear Cache)
  • Lyrics cache (local lyrics files, plus text fetched from LRCLIB if you enabled online lyrics) and AI translation results (clearable the same way)
  • AI translation service address, model name and API key (if you entered one) — the key is kept only in the system Keychain

以下はアプリのサンドボックス内に保存され、アプリを削除すると消去されます。端末の外に出ることはありません：

  • ライブラリの索引、お気に入り、プレイリスト、再生キュー、再生履歴
  • 追加した音楽ソースのアドレスと認証情報（暗号化して保存）
  • ジャケットのサムネイルとネットワーク音声キャッシュ（「設定 → キャッシュを消去」でいつでも削除できます）
  • 歌詞キャッシュ（ローカルの歌詞ファイル、およびオンライン歌詞を有効にした場合に LRCLIB から取得したテキスト）と AI 翻訳の結果（同じ方法で削除できます）
  • AI 翻訳のサービスアドレス、モデル名、API キー（入力した場合）— キーはシステムの Keychain にのみ保存されます

  • 本地网络：用于搜索并连接你所在局域网中的 SMB / DLNA 服务器，以及在你开启文件传输时，在局域网内提供文件上传网页。
