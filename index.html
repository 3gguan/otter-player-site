开始使用 開始使用 Getting Started はじめに

Otter Player 是一款本地音乐播放器：音乐保存在你的设备或你自己的服务器上。

把音乐放进来有三种方式：

  • 文件 App：拷贝到「我的 iPhone → Otter Player」，再从「音乐源 → 默认」进入浏览。
  • 文件传输：打开「设置 → 文件传输」，用电脑浏览器访问 App 里显示的地址上传。
  • 音乐源：添加局域网服务器（SMB、NFS、WebDAV、DLNA），或添加手机上的其它文件夹。

在目录里长按歌曲选「添加到音乐库」，就能在「音乐库」里按专辑、艺术家、流派等分类浏览。

Otter Player 是一款本機音樂播放器：音樂保存在你的裝置或你自己的伺服器上。

把音樂放進來有三種方式：

  • 檔案 App：拷貝到「我的 iPhone → Otter Player」，再從「音樂源 → 預設」進入瀏覽。
  • 檔案傳輸：打開「設定 → 檔案傳輸」，用電腦瀏覽器連上 App 顯示的位址上傳。
  • 音樂源：加入區域網路伺服器（SMB、NFS、WebDAV、DLNA），或加入手機上的其它資料夾。

在目錄裡長按歌曲選「新增到音樂庫」，就能在「音樂庫」裡依專輯、演出者、曲風等分類瀏覽。

Otter Player is a local music player: your music stays on your device or on your own server.

There are three ways to get music in:

  • Files app: copy files into "On My iPhone → Otter Player", then browse them from "Sources → Default".
  • File Transfer: turn it on in "Settings → File Transfer" and upload from your computer's browser using the address shown in the app.
  • Sources: add a server on your local network (SMB, NFS, WebDAV, DLNA), or add another folder on your iPhone.

Long-press a song in a folder and choose "Add to Library"; it then shows up under Library by album, artist, genre and more.

Otter Player はローカル音楽プレイヤーです。音楽はお使いのデバイスまたはご自身のサーバーに保存されます。

音楽を追加する方法は 3 つあります：

  • ファイル App：「この iPhone 内 → Otter Player」にコピーし、「音楽ソース → デフォルト」から開きます。
  • ファイル転送：「設定 → ファイル転送」をオンにし、アプリに表示されたアドレスをパソコンのブラウザで開いてアップロードします。
  • 音楽ソース：同じネットワーク上のサーバー（SMB、NFS、WebDAV、DLNA）や、iPhone 内の別のフォルダを追加します。

フォルダ内の曲を長押しして「ライブラリに追加」を選ぶと、「ライブラリ」でアルバム・アーティスト・ジャンル別に閲覧できます。

常见问题 常見問題 Troubleshooting よくある質問

  • 音乐库是空的？ 音乐需要先「添加到音乐库」：在「音乐源」或目录里长按歌曲即可添加。
  • 网络源连不上？ 确认手机与服务器在同一个局域网，并检查地址、用户名和密码。
  • 封面不显示？ 封面取自音乐文件内嵌的图片，文件里没有内嵌封面时不会显示。
  • 歌词不显示？ 把歌词文件放到音乐文件所在的文件夹并保持同名，扩展名用 lrc、ttml 或 qrc 等。
  • 能不能自动获取歌词？ 可以：在「设置 → 歌词 → 在线歌词」开启。开启后，只有在既没有内嵌歌词、同目录也没有歌词文件时，才会用歌名、歌手、专辑和时长向 lrclib.net 查询纯文本歌词。该开关默认关闭，只发送上述几项元数据，不会上传音频；查到的歌词缓存在本机，之后离线也能看。在线歌词数据由 LRCLIB 提供。
  • 歌词发音和翻译？ 发音（假名、拼音等）在本机计算，不需要联网。翻译需要你在「设置 → 歌词 → AI 歌词翻译」里自行填写一个兼容的翻译服务地址；留空时该功能不会发起任何请求。
  • 播放没有声音？ 检查是否连了蓝牙设备，或试听其它歌曲确认音频文件本身是否正常。
  • 音樂庫是空的？ 音樂需要先「新增到音樂庫」：在「音樂源」或目錄裡長按歌曲即可新增。
  • 網路來源連不上？ 確認手機與伺服器在同一個區域網路，並檢查位址、使用者名稱和密碼。
  • 封面不顯示？ 封面取自音樂檔案內嵌的圖片，檔案裡沒有內嵌封面時不會顯示。
  • 歌詞不顯示？ 把歌詞檔案放到音樂檔案所在的資料夾並保持同名，副檔名用 lrc、ttml 或 qrc 等。
  • 能不能自動取得歌詞？ 可以：在「設定 → 歌詞 → 線上歌詞」開啟。開啟後，只有在既沒有內嵌歌詞、同資料夾也沒有歌詞檔案時，才會用歌名、演出者、專輯和長度向 lrclib.net 查詢純文字歌詞。該開關預設關閉，只傳送上述幾項中繼資料，不會上傳音訊；查到的歌詞會快取在本機，之後離線也能看。線上歌詞資料由 LRCLIB 提供。
  • 歌詞發音與翻譯？ 發音（假名、拼音等）在本機計算，不需要連網。翻譯需要在「設定 → 歌詞 → AI 歌詞翻譯」自行填寫一個相容的翻譯服務位址；留空時該功能不會發出任何請求。
  • 播放沒有聲音？ 檢查是否連接了藍牙裝置，或試聽其它歌曲確認音訊檔案本身是否正常。
  • Library looks empty? Songs must be added first: long-press a song in Sources or a folder and choose "Add to Library".
  • Network source will not connect? Make sure the phone and the server are on the same local network, and check the address, username and password.
  • No artwork? Artwork comes from the image embedded in the music file; if the file has none, nothing is shown.
  • No lyrics? Put the lyrics file in the same folder as the music file with the same name, using an extension such as lrc, ttml or qrc.
  • Can lyrics be fetched automatically? Yes — turn on "Settings → Lyrics → Online Lyrics". Once enabled, only when a track has no embedded lyrics and no lyrics file beside it, the app looks up plain-text lyrics on lrclib.net using the title, artist, album and duration. The switch is off by default, only those metadata fields are sent, and no audio is uploaded. Results are cached on your device, so they stay readable offline. Online lyrics data is provided by LRCLIB.
  • Lyrics pronunciation and translation? Pronunciation (kana, pinyin and so on) is computed on your device and needs no network. Translation requires you to enter a compatible translation service address in "Settings → Lyrics → AI Lyrics Translation"; left empty, the feature makes no requests at all.
  • No sound? Check whether a Bluetooth device is connected, or try another song to see whether the audio file itself is fine.
  • ライブラリが空？ 曲は先に「ライブラリに追加」する必要があります。「音楽ソース」やフォルダで曲を長押しして追加してください。
  • ネットワークソースに接続できない？ iPhone とサーバーが同じネットワークにあるか、アドレス・ユーザー名・パスワードをご確認ください。
  • ジャケットが表示されない？ ジャケットは音楽ファイルに埋め込まれた画像を使用します。埋め込みがない場合は表示されません。
  • 歌詞が表示されない？ 歌詞ファイルを音楽ファイルと同じフォルダに同じ名前で置いてください。拡張子は lrc、ttml、qrc などです。
  • 歌詞を自動取得できますか？ できます。「設定 → 歌詞 → オンライン歌詞」をオンにしてください。オンにした場合でも、埋め込み歌詞がなく、同じフォルダに歌詞ファイルもない曲に限り、曲名・アーティスト・アルバム・再生時間を使って lrclib.net にテキスト歌詞を問い合わせます。このスイッチは初期状態でオフで、送信するのは上記のメタデータのみ、音声はアップロードしません。取得した歌詞は端末内にキャッシュされるため、オフラインでも表示できます。オンライン歌詞のデータは LRCLIB が提供しています。
  • 歌詞の発音と翻訳は？ 発音（かな・ピンインなど）は端末内で計算するため通信は不要です。翻訳は「設定 → 歌詞 → AI 歌詞翻訳」で互換性のある翻訳サービスのアドレスを入力する必要があります。空欄のままでは一切リクエストを送信しません。
  • 音が出ない？ Bluetooth 機器に接続していないか確認するか、別の曲を再生してファイル自体を確認してください。
